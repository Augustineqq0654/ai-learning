# 不能交给AI做的事



**一句话概括：AI 可以负责生成和处理，人必须负责选择、授权、核验与担责。**

| 能交给 AI                                                    | 不能交给 AI（独立完成或最终决定）                           |
| ------------------------------------------------------------ | ----------------------------------------------------------- |
| 1. **整理资料**：归类、去重、提取重点、转换格式              | 1. **确定目标与优先级**：决定真正要解决什么、什么更重要     |
| 2. **生成初稿**：邮件、方案、文案、翻译和代码框架            | 2. **做高风险最终决定**：医疗、法律、重大投资等             |
| 3. **执行重复任务**：规则明确、输入稳定、结果容易检查的工作  | 3. **做价值与伦理取舍**：涉及公平、底线和人的重大利益       |
| 4. **提供备选方案**：头脑风暴、对比选项、查漏补缺            | 4. **执行高风险不可逆操作**：转账、删库、生产发布、授予权限 |
| 5. **校对与初步检查**：润色表达、检查格式、发现代码和逻辑问题 | 5. **替人承担责任**：签字、承诺、审批，以及对结果最终负责   |
